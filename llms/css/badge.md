# Badges

## Basic badges

The `.a_badge_*` classes set badge styles.

## Rounded badges

Add `.a_pill_rounded` to round badges.

## CSS variables (`scss/utils/badge.scss`)

| name | value | description |
| --- | --- | --- |
| `--a_badge_padding_x` |  | Horizontal padding. Relative to the font size. |
| `--a_badge_padding_y` |  | Vertical padding. Relative to the font size. |
| `--a_badge_font_size` |  | Font size, relative to the surrounding text. |
| `--a_badge_font_weight` |  | Font weight. |
| `--a_badge_color` |  | Text color. Set by the color classes (e.g. .a_badge_success). |
| `--a_badge_bg` |  | Background. Set by the color classes. |
| `--a_badge_border_radius` |  | Corner radius. .a_pill_rounded makes it fully round. |
