# aloha-vue: guide for AI agents

> Generated by `npm run build-llms` from the docs (`docs/scripts/build-llms.mjs`, this text: `docs/scripts/AGENTS.template.md`). Do not edit `AGENTS.md` and `llms/` by hand.

**aloha-vue** is an accessible component library for **Vue 3**. Version 3.x.

- Components start with `A`: `AButton` → `<a-button>`. All exports are listed in `src/index.js`.
- CSS classes start with `a_` (`a_btn`, `a_mt_3`), CSS custom properties with `--a_` (`--a_color_primary`).
- Every page of the docs is in `llms/` (list below): props, slots, events, exposes, CSS variables and examples. **Read the page of a component before using it, do not guess props.**
- The sources are in `src/`, the styles in `scss/`.

## Setup

```bash
npm install aloha-vue aloha-svg
```

`main.js`:

```js
import { createApp } from "vue";
import App from "./App.vue";
import "aloha-vue/dist/aloha-vue.css"; // or @use "aloha-vue/scss/aloha-vue"; in your SCSS
import {
  AComponentsPlugin,
  AI18nPlugin,
  AIconPlugin,
  AMobilePlugin,
  i18nDE,
  i18nEN,
} from "aloha-vue";
import Bell from "aloha-svg/dist/js/bootstrap/Bell";
import myDe from "./i18n/de.json";
import myEn from "./i18n/en.json";

const app = createApp(App);

// Translations: dictionaries of the library + own dictionaries, start language
app.use(AI18nPlugin, {
  de: { ...i18nDE, ...myDe },
  en: { ...i18nEN, ...myEn },
}, "de");

// Icons for the props icon, icon-left, icon-right… (name → svg string)
app.use(AIconPlugin, { icons: { Bell } });

// Mobile view below this width (px)
app.use(AMobilePlugin, { breakpoint: 991 });

// Optional: defaults and settings of the components
app.use(AComponentsPlugin, {
  AModal: { props: { closeButtonClass: "a_btn a_btn_link" } },
  ATable: { props: { isStriped: true } },
});

app.mount("#app");
```

Components are imported where they are used:

```js
import { AButton, AModal } from "aloha-vue";

export default {
  components: { AButton, AModal },
};
```

Other plugins (`AHttpPlugin`, `ADataRetrievePlugin`, `AFormPlugin`, `APageTabTitlePlugin`, `ARemPxPlugin`) are only needed for the features they configure, see `llms/plugins/` and `src/plugins/`.

## Translations

- Text props (`text`, `html`, `safe-html`, `label`, `placeholder`, `title`, `aria-label`…) accept a key of the dictionary, e.g. `text="_SAVE_"`. A text that is not a key is shown as it is.
- Placeholders: `"_HELLO_": "Hello {{ name }}"` + `:extra="{ name: 'Anna' }"`.
- Own texts in templates: `<a-translation tag="p" text="_MY_KEY_" />`, see `llms/components/translation.md`.
- In JavaScript: `getTranslatedText({ placeholder: "_MY_KEY_", extra })`.
- Change the language: `setLanguage("en")`. Add keys later: `updateI18nForLanguage({ language: "en", i18n: { … } })`.
- Dictionaries of the library: `i18nAR`, `i18nDE`, `i18nEN`, `i18nES`, `i18nFR`, `i18nHR`, `i18nIT`, `i18nNL`, `i18nPL`, `i18nRU`, `i18nUK`. Their keys are listed in the section **Translations** of each component page.

## Filters and utils

Pure functions for formatting, also usable outside of components:

```js
import { filterCurrency, filterDate } from "aloha-vue";

filterCurrency(1234.5); // "1.234,50 €"
```

In `setup()` they are also available with `const { filterCurrency } = AFiltersAPI();`. All filters: `llms/functions/`.

## Styles

- Utility classes for spacing, colors, display, text…: `llms/css/`. Prefer them to own CSS.
- Theming with CSS custom properties: `llms/css/theming.md`. Every component page ends with its CSS variables.

## Rules

- Use the components and props described in `llms/`. If something is missing, check the props in `src/<Component>/<Component>.js`.
- Keep the accessibility: give buttons with only an icon a `title` or `aria-label`, give form elements a `label`.
- Migration from 2.x: `llms/migrations/migrations-version2-to3.md`.
