# APageTabTitle

Sets the browser document title from a translated string.

Reference for the repository build of `aloha-vue@3.0.0-alpha.1`. See the [quick start](../quick-start.md) for package differences.

## Usage

```js
import { APageTabTitle } from "aloha-vue";
```

[Runnable Vue example](../examples/APageTabTitle.vue) · [Application setup](../quick-start.md) · [Interactive documentation](https://ilia-brykin.github.io/aloha/page-tab-title-plugin)

Install APageTabTitlePlugin when the application needs a shared base title.
