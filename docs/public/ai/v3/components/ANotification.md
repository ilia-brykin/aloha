# ANotification

Application-level host for dismissible notifications.

Reference for the repository build of `aloha-vue@3.0.0-alpha.1`. See the [quick start](../quick-start.md) for package differences.

## Usage

```js
import { ANotification } from "aloha-vue";
```

[Runnable Vue example](../examples/ANotification.vue) · [Application setup](../quick-start.md) · [Interactive documentation](https://ilia-brykin.github.io/aloha/notification)

Mount once and call ANotificationAPI_addNotification to enqueue a message. Choose messages that make sense when announced separately.
