# aloha-vue starter

Vite + Vue 3 + [aloha-vue](https://github.com/ilia-brykin/aloha): translations (de, en), icons, a form and a table.

```bash
npx degit ilia-brykin/aloha/starter my-app
cd my-app
npm install
npm run dev
```

- `src/main.js`: plugins (translations, icons, mobile view)
- `src/App.vue`: components
- `src/i18n/*.json`: own texts
- `AGENTS.md`, `CLAUDE.md`: tell AI agents to read the docs of aloha-vue in `node_modules/aloha-vue/AGENTS.md`

Docs: https://ilia-brykin.github.io/aloha/
