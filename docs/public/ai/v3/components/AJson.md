# AJson

Editable JSON value rendered as a form control.

Reference for the repository build of `aloha-vue@3.0.0-alpha.1`. See the [quick start](../quick-start.md) for package differences.

## Usage

```js
import { AJson } from "aloha-vue";
```

[Runnable Vue example](../examples/AJson.vue) · [Application setup](../quick-start.md) · [Interactive documentation](https://ilia-brykin.github.io/aloha/json)

Bind structured data and keep the rendered editing control labelled.
