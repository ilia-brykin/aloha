# Text Styles

## Font Size

**CSS** classes for controlling font size. Use classes from **.a_fs_1** to **.a_fs_7** to set various text sizes in your application.

```html
<div class="a_fs_1"><code class="a_color_danger">.a_fs_1</code> Text</div>
<div class="a_fs_2"><code class="a_color_danger">.a_fs_2</code> Text</div>
<div class="a_fs_3"><code class="a_color_danger">.a_fs_3</code> Text</div>
<div class="a_fs_4"><code class="a_color_danger">.a_fs_4</code> Text</div>
<div class="a_fs_5"><code class="a_color_danger">.a_fs_5</code> Text</div>
<div class="a_fs_6"><code class="a_color_danger">.a_fs_6</code> Text</div>
<div class="a_fs_7"><code class="a_color_danger">.a_fs_7</code> Text</div>
```

## Text Transformation

**CSS** classes for changing text case and formatting. Use **.a_text_lowercase** for lowercase, **.a_text_uppercase** for uppercase, **.a_text_capitalize** for capitalizing the first letter of each word, as well as classes for underlining and striking through text. **.a_text_underline_offset** underlines the text with a little space under it, **.a_text_line_through_muted** strikes through secondary text, e.g. an old price.

```html
<div><code class="a_color_danger a_mr_2">.a_text_lowercase</code><span class="a_text_lowercase">TEXT</span></div>
<div><code class="a_color_danger a_mr_2">.a_text_uppercase</code><span class="a_text_uppercase">Text</span></div>
<div><code class="a_color_danger a_mr_2">.a_text_capitalize</code><span class="a_text_capitalize">text</span></div>
<div><code class="a_color_danger a_mr_2">.a_text_underline</code><span class="a_text_underline">Text</span></div>
<div><code class="a_color_danger a_mr_2">.a_text_line_through</code><span class="a_text_line_through">Text</span></div>
<div><code class="a_color_danger a_mr_2">.a_text_decoration_none</code><span class="a_text_decoration_none">Text</span></div>
<div><code class="a_color_danger a_mr_2">.a_text_underline_offset</code><span class="a_text_underline_offset">Text</span></div>
<div><code class="a_color_danger a_mr_2">.a_text_line_through_muted</code><span class="a_text_line_through_muted">49,99 €</span><strong class="a_ml_2">39,99 €</strong></div>
```

## Font Weight

**CSS** classes for controlling font weight and style. Includes options from light (**.a_text_light**) to bold (**.a_text_bold**, **.a_text_bolder**), as well as italic (**.a_text_italic**) and normal style (**.a_text_normal**).

```html
<div class="a_text_bold"><code class="a_color_danger a_mr_2">.a_text_bold</code>Text</div>
<div class="a_text_bolder"><code class="a_color_danger a_mr_2">.a_text_bolder</code>Text</div>
<div class="a_text_semibold"><code class="a_color_danger a_mr_2">.a_text_semibold</code>Text</div>
<div class="a_text_light"><code class="a_color_danger a_mr_2">.a_text_light</code>Text</div>
<div class="a_text_lighter"><code class="a_color_danger a_mr_2">.a_text_lighter</code>Text</div>
<div class="a_text_italic"><code class="a_color_danger a_mr_2">.a_text_italic</code>Text</div>
<div class="a_text_normal"><code class="a_color_danger a_mr_2">.a_text_normal</code>Text</div>
```

## Monospace and numbers

**.a_text_monospace** sets the monospace font for IDs, hashes and code. **.a_text_tabular_nums** gives all digits the same width, so numbers in columns line up.

```html
<span class="a_text_monospace">3f9a1c7e-42b0-4d1e</span>

<div class="a_text_tabular_nums a_text_right">
  <div>1 111,11</div>
  <div>8 888,88</div>
  <div>10 101,01</div>
</div>
```

## Text Wrapping

**CSS** classes for controlling text wrapping. Includes normal wrapping (**.a_text_wrap**), no wrapping (**.a_text_nowrap**), forced wrapping of long words (**.a_text_break**), hyphenated wrapping (**.a_text_wrap_hyphens**), and truncation with ellipsis (**.a_text_truncate**).

```html
<div><code class="a_color_danger a_mr_2">.a_text_wrap</code><div class="a_badge a_text_wrap" style="width: 6rem;">Lorem ipsum dolor sit amet consectetur adipisicing elit</div></div>
<div class="a_mt_3"><code class="a_color_danger a_mr_2">.a_text_nowrap</code><div class="a_text_nowrap a_bg_gray_300" style="width: 6rem;">Lorem ipsum dolor sit amet consectetur adipisicing elit</div></div>
<div class="a_mt_3"><code class="a_color_danger a_mr_2">.a_text_break</code><div class="a_text_break" style="width: 10rem;">aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa</div></div>
<div class="a_mt_3"><code class="a_color_danger a_mr_2">.a_text_wrap_hyphens</code><div class="a_text_wrap_hyphens" lang="en" style="width: 10rem;">pneumonoultramicroscopicsilicovolcanoconiosis</div></div>
<div class="a_mt_3"><code class="a_color_danger a_mr_2">.a_text_truncate</code><div class="a_text_truncate" style="width: 6rem;">Lorem ipsum dolor sit amet consectetur adipisicing elit</div></div>
```
